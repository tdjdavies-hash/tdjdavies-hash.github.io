The Open Group
Digital Portfolio

A member-facing digital portfolio platform for The Open Group — an international standards body. Redesigning how members discover, navigate and engage with frameworks, standards and publications.

Client

The Open Group

Scope

UI Design, UX Research

Year

2024

Deliverable

Design System + Prototypes

Interface Design

A cleaner way to navigate complex standards

The existing platform made it difficult for members to find relevant standards across The Open Group's wide portfolio. The redesign introduced a structured navigation model with contextual filtering, improved content hierarchy, and a visual identity consistent with The Open Group's established brand.

Design System

Components built for clarity

A consistent component library was built in Adobe XD and documented as a shared design system — ensuring scalable, on-brand delivery across the platform, from standard cards and data tables through to navigation patterns and search.

Process

From research to live platform

Discovery interviews with member users shaped the information architecture, Adobe XD drove the design phase, and close collaboration with the development team ensured every asset translated faithfully into Antora — The Open Group's documentation platform.

01

Research & Information Architecture

  • Facilitated discovery interviews with member users — enterprise architects, security professionals and IT strategists — to surface pain points around navigation and content discoverability
  • Analysed existing platform analytics to quantify drop-off points and identify the highest-friction journeys
  • Restructured the information architecture, reducing average click depth from 4.2 to 1.8 clicks to content
  • Mapped user flows and produced low-fidelity wireframes to validate the new structure before moving into visual design
02

UI Design in Adobe XD

  • Built a full design system in Adobe XD — components, colour tokens, typography, spacing and grid — aligned to The Open Group brand guidelines (Arial, #2a546d, #017d66, #73c3ed, #82a3af)
  • Designed all core screen states: dashboard, standards library, framework detail pages, search results, and member profile
  • Created interactive prototypes in XD for usability testing, enabling two rounds of structural iteration before developer handoff
  • Documented all component variants, states and usage guidance within the XD file for developer reference
03

Developer Handoff & Antora Build

  • Worked closely with the development team throughout the build, attending sprint reviews and providing design QA at each stage
  • Prepared and exported all assets — icons, illustrations, logos and component specifications — in formats suitable for implementation within Antora, The Open Group's static site documentation platform
  • Created a handoff guide covering CSS variables, spacing tokens and responsive breakpoints to ensure pixel-accurate translation from XD to Antora
  • Provided ongoing design support during development, resolving edge cases and adapting components where Antora's constraints required creative solutions

Overview

Designing for expert users

The Open Group's membership includes enterprise architects, security professionals and IT strategists who rely on standards daily. The challenge was building an interface sophisticated enough for expert users while remaining accessible to those newer to the portfolio. The redesign introduced a role-based dashboard model with personalised content surfacing, a restructured IA reducing average click depth from 4.2 to 1.8, and a design system ensuring consistent delivery across the full Antora-powered platform.
